## Conflicts to watch

Flagged only: the voice is recorded, so the video's wording stays as it is.

- Row 2 (b05 "it averages just 177 kilometers"): Memoria Chilena (row 1's second source, independent of the Library of
  Congress text that Wikipedia copies) gives an average width of 200 km. 177 km is area divided by length: Memoria
  Chilena's own area of 756,626 km² / 4,270 km = 177.2 km, so it is a defensible mean and the figures differ in how
  the average is taken. Researcher-reported, not verified (search snippet; the page returned 403): Britannica's
  average is about 110 mi, which is 177 km.
- Row 3 (b01 "24 times longer than it is wide"): true for the 177 km average (4,270 / 177 = 24.1). Memoria Chilena's
  200 km would give 4,270 / 200 = 21.35, but its own area figure gives the same ratio (4,270² / 756,626 = 24.1). No
  source states the ratio itself.
